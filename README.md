# Mini Hospital Emergency Management System

## Project Description
This is a Java-based console application developed as part of the CIT300 - Data Structures and Algorithms individual mid assignment. The system simulates the management of patients arriving at a hospital, including registration, emergency queuing, treatment completion, and visit history tracking.

## Features Implemented
1. Patient Records (BST): Insert, Search, Delete, Inorder Traversal
2. Emergency Queue (Queue): Enqueue, Dequeue, Display
3. Treatment History (Stack): Push, Pop, Display
4. Patient Visit History (Singly Linked List):** Add, Remove, Search, Display

## How to Run the Program
1. Open Terminal in VS Code (`Ctrl + `` ).
2. Compile: `javac Main.java`
3. Run: `java Main`
